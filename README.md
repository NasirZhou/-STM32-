# -STM32-
基于FreeRTOS的智能手表，集成抬腕显示、心率血氧监测、GPS定位及步数统计。多任务调度与队列通信优化效率，任务优先级管理实现功能切换，结合传感器采集数据，利用ESP8266远程同步，打造低功耗方案。 /FreeRTOS-based smartwatch with wrist-lift, HR/BloodO2 monitoring, GPS, step counting. Multi-tasking/queues boost efficiency. Task priority switching. Collects sensor data, syncs via ESP8266. Low-power solution.
